# Code of conduct / 社区行为准则

## Our community / 社区约定

AID welcomes contributors and users of different backgrounds and experience levels. Participate respectfully in issues, pull requests, reviews and project community spaces.

AID 欢迎不同背景和经验的使用者与贡献者。请在 Issue、PR、代码审查与项目社区中尊重彼此。

## Expected behavior / 鼓励的行为

- Discuss ideas and code with concrete evidence; give constructive feedback.
- Be patient with newcomers and people using a different language.
- Respect privacy, authorship, copyright and contributors' time.
- Acknowledge mistakes and help resolve disagreements productively.

讨论问题时提供事实和建设性建议；耐心帮助新参与者；尊重隐私、版权和他人的时间；发现错误时主动纠正。

## Unacceptable behavior / 不接受的行为

- Harassment, threats, discriminatory language or personal attacks.
- Sexual harassment or unwelcome sexual content.
- Publishing someone else's personal information or private communications without permission.
- Impersonation, spam, unrelated advertising or deliberately disruptive activity.

禁止骚扰、威胁、歧视、人身攻击、性骚扰、冒充他人、垃圾广告，以及未经同意公开个人信息或私人交流内容。

## Reporting and moderation / 报告与处理

For conduct concerns, contact a project maintainer privately through the [community contact entry](README.md#交流与反馈). Ask a group administrator for a private conversation; do not post personal details to the group. If a concern involves one maintainer, contact another available maintainer or use [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

维护者可根据问题严重程度要求修改内容、移除不当内容、限制参与或暂停访问，并尽量保护报告者隐私。如果问题涉及某位维护者，请联系其他可用维护者，或通过 GitHub 举报入口处理。

Maintainers may request changes, remove inappropriate content, restrict participation or suspend access according to the seriousness and recurrence of the behavior. Reports should be handled with care for the reporter's privacy. These expectations apply when someone represents the project in public as well as within project spaces.

For software vulnerabilities, use the separate [security policy](SECURITY.md).
